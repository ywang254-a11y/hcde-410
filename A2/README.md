A2: Exploring Sources of Bias in Data

This assignment explores potential sources of bias in the Wikipedia Talk Corpus, focusing on annotator demographics, missing data, duplicate records, and how these limitations might affect toxicity classification.

The analysis was conducted using Python and Jupyter Notebook.
